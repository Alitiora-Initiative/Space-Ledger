A SIMPLE TEST FLOW

From wallet to receipt.

The canvas uses whole-block primary purchases on Solana Devnet—not individual pixel sales.

  1. 01

    Connect on Devnet

    Use a compatible Solana wallet and switch its network to Devnet before starting.

  2. 02

    Explore and get a quote

    Choose a whole block, review the quote and check that the test-token balance is sufficient.

  3. 03

    Approve and verify

    Approve in your wallet, then use the transaction and receipt details to verify the result.

Keep the network straight. The canvas and its Anchor program run on Devnet. Never send Mainnet assets through the canvas purchase flow. Read the mobile wallet guide.

CLEAR SCOPE. NO GUESSWORK.

What is live—and what is not.

A prototype should be clear about its current limits. These boundaries are part of the product, not fine print.

Available in beta

Whole-block purchases

Primary purchases, Devnet receipts, grid exploration, profile and activity views.

Not implemented

Pixel-level ownership and resale

Individual pixel ownership, transfers, a secondary market and redemption are not live features.

Security status

Independent audit pending

The Anchor program has not completed an independent security audit. Treat this as a Devnet prototype, not a production financial system.
