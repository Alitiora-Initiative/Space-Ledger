Privacy Policy

Last reviewed: 12 October 2026

Publication status: incomplete. The project owner has identified Kenya as their home country, but this site does not yet publish the operator's legal name, postal contact, or a privacy email. Hosting and RPC provider retention terms also depend on the live deployment. Those details must be completed before this can serve as a final global privacy notice.

This policy describes the Space Ledger website and the code currently in this repository. It is a factual code review, not a certification that the service complies with every law in every country.

Who operates Space Ledger

Space Ledger is an individual project operated from Kenya. The operator's full legal name, service address, and privacy contact are not published in this build. A data controller's identity and contact details are required in some jurisdictions; this notice remains incomplete until the operator supplies them.

Information the site handles

  • Wallet details: if you choose a detected, compatible Solana wallet, it provides a public address to the page for the requested feature. The site does not request a recovery phrase or private key. Addresses and transactions written to a public blockchain can be visible permanently and may be linkable to a person.
  • Feature requests: the site sends the wallet address, selected asset, amount, block range, or public chain query needed to provide a feature you request. A Devnet purchase flow, when configured, asks your wallet to review and sign a transaction; it does not move mainnet funds.
  • Network metadata: the web host and network security services may process an IP address, requested URL, time, browser details, and error information to deliver and protect the site. The hosting provider and its retention period are not configured in this repository.

Why information is used

Requests are processed to show public chain data, calculate estimates, prepare a Devnet transaction when available, respond to a wallet connection you initiate, and maintain the service. The operator must document the applicable lawful basis for each purpose and any security-log retention before public launch; this code review cannot choose a lawful basis for an unidentified controller.

Blockchain and service providers

Solana requests use the public Devnet endpoint by default. The network explorer sends requested, read-only EVM queries through the server to the RPC endpoints shown on that page. These services receive the query data needed to answer the request and may process their own connection metadata under their own terms. A wallet extension or wallet app is contacted only when you choose a wallet action. Solana Explorer is opened only when you follow a transaction link.

Public blockchain records are controlled by the network, not by this website. The site cannot remove or change a confirmed public transaction. Provider locations, transfer safeguards, and retention periods must be checked against the provider selected by the live deployment.

Storage and analytics

The current site code does not set cookies, use local or session storage, run advertising or analytics trackers, or build a browsing profile. It has no account database for wallet addresses. The application processes requested values in memory to answer requests. The deployed host may keep operational logs; its exact settings are not available in this repository.

Retention and security

The application code does not persist wallet addresses or browsing histories in a user database. Public blockchain data remains on the relevant network. Hosting and RPC providers may retain records under their own policies. No internet service can promise absolute security; the operator must publish deployment-specific retention and security contact details.

Your rights and contact

Depending on where you live, privacy law may give you rights to be informed, access or correct personal data, object to some processing, or request deletion where applicable. Kenya's Data Protection Act sets out data-protection principles and data-subject rights; the Office of the Data Protection Commissioner publishes information about those rights. Other countries have their own rules and regulators. This build does not provide a privacy email or postal address for requests. The operator must add a working private contact channel before launch. Do not post wallet or identity details in a public issue tracker.

Changes

If the site adds analytics, cookies, embeds, new wallet providers, or a new purpose for personal data, this policy and the site's controls must be reviewed before the feature is enabled.
