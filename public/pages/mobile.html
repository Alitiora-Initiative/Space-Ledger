Choose your Space Ledger workspace

Full workspace on Windows, macOS and tablets. A lighter explorer is available on phones.

Full workspace — recommended

Use a Windows or macOS laptop/desktop, or a tablet such as an iPad. These devices receive the full browser interface, including the larger world view and workspace layouts.

Space Ledger can be installed as a Progressive Web App (PWA) where supported. This is one cross-platform web app, not a Windows-only executable. A Windows executable does not run natively on macOS.

Open desktop workspace

Install on Windows

  1. Open Space Ledger in Microsoft Edge or Google Chrome.
  2. Use the browser's Install app / Install page as app option.
  3. Confirm installation. It opens in its own window and can be pinned to Start or the taskbar.

Install on macOS

  1. Open Space Ledger in Safari on macOS Sonoma 14 or later.
  2. Choose File → Add to Dock, or Share → Add to Dock.
  3. Open the web app from the Dock or Applications folder.

Chrome and Edge also offer install-as-app options where available. Installation is optional; the full website works in a normal browser.

iPad and Android tablets

Tablets use the full workspace tier. On iPad, open the page in Safari, tap Share → Add to Home Screen and turn on Open as Web App. On Android tablets, use the browser's Install app option when offered.

Mobile Lite

Phones are optimised for browsing the world, inspecting blocks, reading confirmed activity and reviewing holdings. Desktop-heavy workspace layouts are reduced to preserve screen space and device resources.

For Devnet signing, open the website in a wallet's own in-app browser. The buttons below use official wallet browse links; they do not include a transaction, private key or seed phrase.
