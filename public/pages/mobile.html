Mobile Devnet testing

Wallet Standard only detects wallets injected in the current browser. On phones, use an in-app browser.

Recommended path (works today)

  1. Install Phantom or Solflare from the official store.
  2. Inside the wallet app, open the in-app browser / explore.
  3. Go to https://space-ledger-alitiora.vercel.app
  4. Switch the wallet network to Devnet.
  5. Connect → Pricing → quote → approve.

Full WalletConnect QR for Solana is not shipped in this beta (tracked as issue #8). Do not paste seed phrases anywhere.
