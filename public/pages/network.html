Multi-Chain Network Configuration

About Multi-Chain Architecture

Spice Ledger uses a multi-chain RPC routing architecture. When an end user or application needs blockchain metadata, the request is sent to a service layer that identifies the target network and forwards the request to the appropriate RPC endpoint.

This enables smoother cross-chain discovery and interaction, supporting Layer 3 applications, app chains, modular rollups, and decentralized RPC nodes.
