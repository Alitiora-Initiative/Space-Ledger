Read-only Network Explorer

About Multi-Chain Architecture

Query public Ethereum-compatible RPC networks using a fixed allowlist of read-only methods. These requests display public chain data and do not connect to your wallet.

Transactions, contract writes, and custom RPC destinations are not accepted by this explorer.

Common RPC Methods

Method Description
eth_blockNumber Get the number of the most recent block
eth_getBalance Get balance of an address
eth_chainId Get the chain ID
eth_gasPrice Get current gas price
net_version Get the network version
