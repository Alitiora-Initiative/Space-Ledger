## Assignment Rules

1. Each agent must have a distinct purpose and measurable deliverables
2. No two agents may have conflicting assignments
3. Each agent must have a clearly defined supervisor
4. Agents must not exceed their granted permissions
5. Agents must report through their designated supervisor
6. Specialized agents are created only when demonstrated need exists
7. Agent retirement requires supervisor approval and handoff documentation

## Agent Lifecycle

### Creation
- Need must be demonstrated and documented
- Agent specification must be complete (per Article V of constitution)
- Permissions must be clearly defined
- Supervisor must be assigned
- Entry must be added to this registry

### Assignment
- Tasks must be within agent's scope
- Required inputs must be available
- Supervisor must authorize assignment
- Assignment must be recorded

### Retirement
- Supervisor must approve retirement
- Useful findings must be preserved
- Audit history must be maintained
- Registry entry must be updated with retirement status and reason

## Conflict Prevention

To prevent conflicting assignments:
- Check registry before assigning new tasks
- Ensure no other agent is working on the same code area
- Coordinate through Gilga Prime for cross-agent work
- Document dependencies between agent tasks
- Escalate conflicts to Gilga Prime
